title: 'det:poss'
shortdef: 'possessive determiner'
udver: '2'
---

Whenever there is a possessive determiner, `det:poss` should be used instead of [det](). All possessive determiners have the feature [Possessive](Poss) defined as `Yes`.

~~~ sdparse
det:poss()
det:poss()
~~~

~~~ sdparse
det:poss()
det:poss()
~~~
