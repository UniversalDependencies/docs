`Number[obj]` is an inflectional feature of [verbs](_oge/pos/VERB).

### <a name="Sing">`Sing`</a>: singular number

#### Examples

* _მპოვებს_ 'he/she finds me', _მხატავ_ 'you draw me' etc.

### <a name="Plur">`Plur`</a>: plural number

#### Examples

* _გუპოვებს_ 'he/she finds us', _გუხატავს_ 'he/she draws us' etc.
