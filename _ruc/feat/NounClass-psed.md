In Ruuli, possessive pronouns agree both with the possessor and the possessee. 
The possessee agreement is marked by the initial morpheme of the possessive pronoun.
Third person possessee marking reflects the noun class of the possessee: `[NounClass[psed]]`, according to the paradigm below.
Noun class agreement with the possessor is annotated with the feature [NounClass[psor]]().

| Noun Class (NC) |Object Prefix |
|------|--------|
| 1 | _wa-_ |
| 2 | _ba-_ |
| 3 | _gu-_ |
| 4 | _gi-_/_za-_ |
| 5 | _li-_ |
| 6 | _ga-_ |
| 7 | _ki-_ |
| 8 | _bi-_ |
| 9 | _ya-_ |
| 10 | _za-_ |
| 11 | _lu-_ |
| 12 | _ka-_ |
| 13 | _tu-_ |
| 14 | _bu-_ |
| 15 | _ku-_ |
| 20 | _gu-_ | 
| 22 | _ga-_ | 

The paradigm of possessee markers excludes locative classes 16, 17, 18, and 23 as they do not contain nouns and cannot be used as objects; 
Proto-Bantu noun classes 19 and 21 are not attested in Ruuli.

### <a name="Bantu1">`Bantu1`</a>: noun class 1

The possessee prefix of noun class 1 is _wa-_.
This class contains singular nouns with human reference. The corresponding plural noun class is `Bantu2` and `Bantu10`.

#### Examples

* _omwana <b>wa</b>-nge_<br>
  NC1.child **NC1.PSED**-1sg.PSOR<br>
  "my child" 

### <a name="Bantu2">`Bantu2`</a>: noun class 2

The possessee prefix of noun class 2 is _ba-_.
This class contains plural nouns with human reference. The corresponding singular noun class is `Bantu1`.

#### Examples

* _abakulu <b>ba</b>-kyo_<br>
  NC2.leaders **NC2.PSED**-NC7.PSOR<br>
  "its leaders"

### <a name="Bantu3">`Bantu3`</a>: noun class 3

The possessee prefix of noun class 3 is _gu-_, realized as _gw-_ due to the following associative vowel.
This class contains singular nouns. The corresponding plural class is `Bantu4`.

#### Examples

* _mugaso <b>gw</b>-agyo_<br>
  NC3.importance **3.PSED**-4.PSOR<br>
  "their importance"

### <a name="Bantu4">`Bantu4`</a>: noun class 4

The possessee prefixes of noun class 4 are _gi-_, realized as _gy-_ due to the following associative vowel, and _za-_.
This class contains plural nouns. The corresponding singular class is `Bantu3`.

#### Examples

* _emirimu <b>gy</b>-ange_<br>
  NC4.activities **NC4.PSED**-1sg.PSOR<br>
  "my activities"

### <a name="Bantu5">`Bantu5`</a>: noun class 5

The possessee prefix of noun class 5 is _li-_, realized as _ly-_ due to the following associative vowel.
This class contains singular nouns. The corresponding plural class is `Bantu6`.

#### Examples

* _eibara <b>ly</b>-amu_<br>
  NC5.name **NC5.PSED**-2sg.PSOR<br>
  "your name"

### <a name="Bantu6">`Bantu6`</a>: noun class 6

The possessee prefix of noun class 6 is _ga-_.
This class contains plural and mass nouns. The corresponding singular class is `Bantu5`.

#### Examples

* _amaaba <b>ga</b>-abwe_<br>
  NC6.departure **NC6.PSED**-NC2.PSOR<br>
  "their departure"

### <a name="Bantu7">`Bantu7`</a>: noun class 7

The possessee prefix of noun class 7 is _ki-_, realized as _ky-_ due to the following associative vowel.
This class contains singular nouns. The corresponding plural class is `Bantu8`.

#### Examples

* _kibanja <b>ky</b>-aiswe_<br>
  NC7.land **NC7.PSED**-1pl.PSOR<br>
  "our land"

### <a name="Bantu8">`Bantu8`</a>: noun class 8

The possessee prefix of noun class 8 is _bi-_, realized as _by-_ due to the following associative vowel.
This class contains plural nouns. The corresponding singular class is `Bantu7`.

#### Examples

* _ebyojo <b>by</b>-abwe_<br>
  NC8.boys **NC8.PSED**-NC2.PSOR<br>
  "their boys"

### <a name="Bantu9">`Bantu9`</a>: noun class 9

The possessee prefix of noun class 9 is ya-.
This class contains singular nouns. The corresponding plural class is `Bantu10`.

#### Examples

* _entikko <b>ya</b>-agwo_<br>
  NC9.culmination **NC9.PSED**-NC3.PSOR<br>
  "its culmination"

### <a name="Bantu10">`Bantu10`</a>: noun class 10

The possessee prefix of noun class 10 is _za-_.
This class contains plural nouns. The corresponding singular classes are `Bantu1`, `Bantu9`, and `Bantu11`.

#### Examples

* _engeso <b>za</b>-alyo_<br>
  NC10.norms **NC10.PSED**-NC5.PSOR<br>
  "its norms"

### <a name="Bantu11">`Bantu11`</a>: noun class 11

The possessee prefix of noun class 11 is _lu-_, realized as _lw-_ due to the following associative vowel.
This class contains singular nouns. The corresponding plural class is `Bantu10`.

#### Examples

* _olwetiiko <b>lw</b>-amu_<br>
  NC11.responsibility **NC11.PSED**-2sg.PSOR<br>
  "your responsibility"

### <a name="Bantu12">`Bantu12`</a>: noun class 12

The possessee prefix of noun class 12 is _ka-_. 
This class contains singular and mass nouns. It is also used to form diminutive singular nouns. 
The corresponding plural class is `Bantu14`.

#### Examples

* _akawoowo <b>ka</b>-gyo_<br>
  NC12.scent **NC12.PSED**-NC9.PSOR<br>
  "its scent"

### <a name="Bantu13">`Bantu13`</a>: noun class 13

The possessee prefix of noun class 13 is _tu-_, realized as _tw-_ due to the following associative vowel.
This class is used to form diminutive mass nouns. 
There is no corresponding plural class.

#### Examples

* _otusabbuuli <b>tw</b>-ange_<br>
  NC13.some_soap **NC13**-1sg.PSOR<br>
  "my small amount of soap"

### <a name="Bantu14">`Bantu14`</a>: noun class 14

The possessee prefix of noun class 14 is _bu-_, realized as _bw-_ due to the following associative vowel.
This class contains multiple abstract nouns. It is also used to form diminutive plural nouns. 
The corresponding singular class is `Bantu12`.

#### Examples

* _obwomi <b>bw</b>-aiswe_<br>
  NC14.life **NC14.PSED**-1pl.PSOR<br>
  "our life"

### <a name="Bantu15">`Bantu15`</a>: noun class 15

The possessee prefix of noun class 15 is _ku-_, realized as _kw-_ due to the following associative vowel.
This class contains deverbal nouns. There is no corresponding plural class.

#### Examples

* _okusoma <b>kw</b>-amu_<br>
  NC15.education **NC15.PSED**-2sg.PSOR<br>
  "your education"

### <a name="Bantu20">`Bantu20`</a>: noun class 20

The possessee prefix of noun class 20 is _gu-_, realized as _gw-_ due to the following associative vowel.
This class is used to form augmentative singular nouns. The corresponding plural class is `Bantu22`.

#### Examples

* _ogubbambo <b>gw</b>-abwe_<br>
  NC20.big_basket **NC20.PSED**-NC2.PSOR<br>
  "their big basket"

### <a name="Bantu22">`Bantu22`</a>: noun class 22

The possessee prefix of noun class 22 is _ga-_.
This class is used to form augmentative plural nouns. The corresponding singular class is `Bantu20`.

#### Examples

* _agajwenge <b>ga</b>-bwe_<br>
  NC22.big_boats **NC22.PSED**-NC2.PSOR<br>
  "their big boats"
