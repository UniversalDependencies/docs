This feature takes the following values: Dem, Emp, Exc, Ind, Int, Neg, Prs, Rcp, Rel, Tot.

### <a name='Dem'>`Dem`: explanation of the value
Demonstrative pronouns can be proximal (like _ēn_) and remote (like _ān_), but there function in discourse reference has not been fully understood yet.<br>"this" _ēn, ēd, im_, "that" _ān, ōy_, "those" _awēšān_

### <a name='Emp'>`Emp`: explanation of the value
The reflexive pronouns _xwad_ can be used as an intensifier, in case of which it receives the feature emphatic.
- _dušox <b>xwad</b> tisē wattar kū bīm_ "Hell **itself** (is) something worse than fear."
- _u=šān <b>xwad</b> pad xwad ān ī abārōn arešk abar burd_ "And they **themselves** brought sinful envy upon themselves."

Negation can be emphasised by using _tisiz_ lit. "even something":
- _ud <b>tisiz</b> bazag az mardōmān **nē** raft_ "And no wrongdoing **at all** started from humans."

### <a name='Exc'>`Exc`: explanation of the value
The exclamative determiner is _čē_ as in _<b>čē</b> xūb_ / _what good_ i.e. "That's good!"

It has not been attested in the corpus yet.

### <a name='Ind'>`Ind`: explanation of the value
Indefinite pronouns include _čand_ "some".

### <a name='Int'>`Int`: explanation of the value
Interrogative pronouns are _kē_ "who", _čē_ "what", _kū_ "where", _kay_ "when", _čiyōn_ "how". They can be used as relative pronouns and interrogative determiners.

### <a name='Neg'>`Neg`: explanation of the value
The only pronoun marked inherently as negative is _ēč_ "any", which usually occurs with a negated predicate.
- _ud pad <b>ēč</b> rāh ruwān ī xwēš **nē** āzāred_ "And (it) does not harm his soul in **any** way."

### <a name='Prs'>`Prs`: explanation of the value
Personal pronouns have orthotone and enclitic forms.

### <a name='Rcp'>`Rcp`: explanation of the value
The reciprical pronoun is _ham_. Elements of analytic expressions such as _ēk ō did_ "one to the other" i.e. "to each other" are annotated individually.

### <a name='Rel'>`Rel`: explanation of the value
All interrogative pronouns can be used as relative pronouns and the word _ī_, which is also used as a linker for attributes to their headword.

### <a name='Tot'>`Tot`: explanation of the value
Total pronouns are _harw_ "every", _hamāg_ and _(har)wisp_ "all".
