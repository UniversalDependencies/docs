The `NameType` feature applies to [proper nouns](_oge/pos/PROPN).


### <a name="Sur">`Sur`</a>: surnames

#### Examples

* _შანიძე_ 'Shanidze', _ჭავჭავაძე_ 'Chavchavadze' etc.

### <a name="Prs">`Prs`</a>: personal names

#### Examples

* _იაკობ_ 'Jacob', _იესუ_ 'Jesus' etc.

### <a name="Geo">`Geo`</a>: geographical names

#### Examples

* _ოპიზა_ 'Opiza', _მტკუარი_ 'Mtkvari' etc.
