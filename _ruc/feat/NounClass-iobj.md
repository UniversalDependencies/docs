The indirect object `iobj` is a core argument of ditransitive predicates in the semantic role of a recipient, a beneficiary, or a source.
The indirect object can be marked on the verb as the second object prefix, following the subject prefix and the prefix of the direct object.

Third-person markers of the indirect object agree with the indirect object in noun class.
Currently, only indirect object prefixes of noun classes 1 and 2 are attested; further work might show that they can extend to other noun classes in [NounClass[obj]]().
(Additionally, first and second person prefixes of indirect objects are attested, but they do not have noun class assignment; their forms reflect [Person[iobj]]() and [Number[iobj]]().)

### <a name="Bantu1">`Bantu1`</a>: noun class 1

The object prefix of noun class 1 is _mu-_.
This class contains singular nouns, mostly for humans. The corresponding plural classes are `Bantu2` and `Bantu10`.

#### Examples

* _Tu-li-<b>mu</b>-toleku._<br>
  1pl.SBJ-NC5.OBJ-**NC1.IOBJ**-remove:SBJV<br>
  "Let us remove it (the spear) from **him**."

### <a name="Bantu2">`Bantu2`</a>: noun class 2

The object prefix of noun class 2 is _ba-_.
This class contains plural nouns, mostly for humans. The corresponding singular class is `Bantu1`.

#### Examples

* _A-bu-<b>ba</b>-toleku._<br>
  NC1.SBJ-NC14.OBJ-**NC2.IOBJ**-remove:SBJV<br>
  "Let him remove it (the leadership) from **them**."
