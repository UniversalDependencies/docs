This feature takes the following values: Acc, Nom, which are traditionally referred to as direct case for nominative and oblique case for accusative.<br>The enclitic pronouns are the only words that are marked for oblique case throughout the history of Middle (and New) Persian. Among orthotone personal pronouns, the 1st singular generalised the oblique form _man_, but the direct form _an_ occurs from time to time.<br>Kinship terms used to have two case forms but those appear to be used interchangeably in the Zoroastrian Middle Persian corpus. Therefor, the generalised form is not annotated as marked for case but only the marked one.

### <a name='Acc'>`Acc`: explanation of the value
This corresponds to all oblique cases including ergative subjects.

### <a name='Nom'>`Nom`: explanation of the value
This corresponds to the direct case, which is used for the object in an ergative construction.
