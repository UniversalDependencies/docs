`Number[io]` is an inflectional feature of [verbs](_oge/pos/VERB).

### <a name="Sing">`Sing`</a>: singular number

#### Examples

* _მაქუს_ 'I have it', _გაქუს_ 'you have it', _ხაქუს_ 'he/she has it' etc.

### <a name="Plur">`Plur`</a>: plural number

#### Examples

* _მაქუს_ 'we have it', _გუაქუს_ 'we have it' etc.
