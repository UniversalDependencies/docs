In Ruuli, possessive pronouns agree both with the possessor and the possessee. 
The possessor agreement is marked by the final morpheme of the possessive pronoun.
The third person possessor agreement cross-references the noun class of the possessor: `[NounClass[psor]]`, according to the paradigm below.
The noun class agreement with the possessee is annotated with the feature [NounClass[psed]]().

| Noun Class (NC) | Possessor marker |
|------|--------|
| 1 | _mwe_ |
| 2 | _bwe_ |
| 3 | _gwo_ |
| 4 | _gyo_ |
| 5 | _lyo_ |
| 6 | _go_ |
| 7 | _kyo_ |
| 8 | _byo_ |
| 9 | _gyo_ |
| 10 | _zo_ |
| 11 | _lwo_ |
| 12 | _ko_ |
| 13 | _two_ |
| 14 | _bwo_ |
| 15 | _kwo_ |
| 20 | _gwo_ | 
| 22 | _go_ | 

The paradigm of the possessor markers excludes locative classes 16, 17, 18, and 23 as they do not contain nouns and are not used as possessors; 
The Proto-Bantu noun classes 19 and 21 are not attested in Ruuli.

### <a name="Bantu1">`Bantu1`</a>: noun class 1

The possessor marker of noun class 1 is _mwe_.
This class contains singular nouns, mostly for humans. The corresponding plural classes are `Bantu2` and `Bantu10`.

#### Examples

* _omwana wa-<b>mwe</b>_<br>
  NC1.child NC1.PSED-**NC1.PSOR**<br>
  "**his/her** child" 

### <a name="Bantu2">`Bantu2`</a>: noun class 2

The possessor marker of noun class 2 is _bwe_.
This class contains plural nouns, mostly for humans. The corresponding singular class is `Bantu1`.

#### Examples

* _amaaba ga-<b>bwe</b>_<br>
  NC6.departure NC6.PSED-**NC2.PSOR**<br>
  "**their** departure"

### <a name="Bantu3">`Bantu3`</a>: noun class 3

The possessor marker of noun class 3 is _gwo_.
This class contains singular nouns. The corresponding plural class is `Bantu4`.

#### Examples

* _entikko ya-<b>gwo</b>_<br>
  NC9.culmination NC9.PSED-**NC3.PSOR**<br>
  "**its** culmination" (e.g. of a function; _mukolo_ 'function (NC3)')

### <a name="Bantu4">`Bantu4`</a>: noun class 4

The possessor marker of noun class 4 is _gyo_.
This class contains plural nouns. The corresponding singular class is `Bantu3`.

#### Examples

* _mugaso gwa-<b>gyo</b>_<br>
  NC3.importance NC3.PSED-**NC4.PSOR**<br>
  "**their** importance" (e.g. of jobs; _milimo_ 'jobs (NC4)')

### <a name="Bantu5">`Bantu5`</a>: noun class 5

The possessor marker of noun class 5 is _lyo_.
This class contains singular nouns. The corresponding plural class is `Bantu6`.

#### Examples

* _engeso za-<b>lyo</b>_<br>
  10.norms NC10.PSED-**NC5.PSOR**<br>
  "**its** norms" (e.g. of a tribe; _iyanga_ 'tribe (NC5)')

### <a name="Bantu6">`Bantu6`</a>: noun class 6

The possessor marker of noun class 6 is _go_.
This class contains plural and mass nouns. The corresponding singular class is `Bantu5`.

#### Examples

* _ekikulu kya-<b>go</b>_<br>
  NC7.purpose NC7.PSED-**NC6.PSOR**<br>
  "**its** purpose" (e.g. of butter; _magita_ 'butter (NC6)')

### <a name="Bantu7">`Bantu7`</a>: noun class 7

The possessor marker of noun class 7 is _kyo_.
This class contains singular nouns. The corresponding plural class is `Bantu8`.

#### Examples

* _abakulu ba-<b>kyo</b>_<br>
  NC2.leaders NC2.PSED-**NC7.PSOR**<br>
  "**its** leaders" (e.g. of a clan; _kika_ 'clan (NC7)')

### <a name="Bantu8">`Bantu8`</a>: noun class 8

The possessor marker of noun class 8 is _byo_.
This class contains plural nouns. The corresponding singular class is `Bantu7`.

#### Examples

* _mwiiku gwa-<b>byo</b>_<br>
  NC3.scent NC3.PSED-**NC8.PSOR**<br>
  "**their** scent" (e.g. of meals; _biibulo_ 'meals (NC8)')

### <a name="Bantu9">`Bantu9`</a>: noun class 9

The possessor marker of noun class 9 is _gyo_.
This class contains singular nouns. The corresponding plural class is `Bantu10`.

#### Examples

* _akawoowo ka-<b>gyo</b>_<br>
  NC12.scent NC12.PSED-**NC9.PSOR**<br>
  "**its** scent" (e.g. of food; _mere_ 'food (NC9)')

### <a name="Bantu10">`Bantu10`</a>: noun class 10

The possessor marker of noun class 10 is _zo_.
This class contains plural nouns. The corresponding singular classes are `Bantu1`, `Bantu9`, and `Bantu11`.

#### Examples

* _amabara ga-<b>zo</b>_<br>
  NC6.names NC6.PSED-**NC10.PSOR**<br>
  "**their** names" (e.g. of cows; _nte_ 'cows (NC10)')

### <a name="Bantu11">`Bantu11`</a>: noun class 11

The possessor marker of noun class 11 is _lwo_.
This class contains singular nouns. The corresponding plural class is `Bantu10`.

#### Examples

* _erangi ya-<b>lwo</b>_<br>
  NC9.color NC9.PSED-**NC11.PSOR**<br>
  "**its** color" (e.g. of wood; _lubaawo_ 'wood (NC11)')

### <a name="Bantu12">`Bantu12`</a>: noun class 12

The possessor marker of noun class 12 is _ko_. 
This class contains singular and mass nouns. It is also used to form diminutive singular nouns. 
The corresponding plural class is `Bantu14`.

#### Examples

* _ebiseera bya-<b>ko</b>_<br>
  NC8.season NC8.PSED-**NC12.PSOR**<br>
  "**its** season" (e.g. of dry spell; _kanyango_ 'dry spell (NC12)')

### <a name="Bantu13">`Bantu13`</a>: noun class 13

The possessor marker of noun class 13 is _two_.
This class is used to form diminutive mass nouns. 
There is no corresponding plural class.

#### Examples

* _mugaso gwa-<b>two</b>_<br>
  NC3.importance NC3.PSED-**NC13.PSOR**<br>
  "**its** importance" (e.g. of some sleep; _tulo_ 'some sleep (NC13)')
  
### <a name="Bantu14">`Bantu14`</a>: noun class 14

The possessor marker of noun class 14 is _bwo_.
This class contains multiple abstract nouns. It is also used to form diminutive plural nouns. 
The corresponding singular class is `Bantu12`.

#### Examples

* _omukama wa-<b>bwo</b>_<br>
  NC1.leader NC1.PSED-**NC14.PSOR**<br>
  "**its** leader" (e.g. of the kingdom; _bukama_ 'kingdom (NC14)')

### <a name="Bantu15">`Bantu15`</a>: noun class 15

The possessor marker of noun class 15 is _kwo_.
This class contains deverbal nouns. There is no corresponding plural class.

#### Examples

* _amarakka ga-<b>kwo</b>_<br>
  NC6.sound NC6.PSED-**NC15.PSOR**<br>
  "**its** sound" (e.g. of thunder; _kubbwatuka_ 'thunder (NC15)')

### <a name="Bantu20">`Bantu20`</a>: noun class 20

The possessor marker of noun class 20 is _gwo_.
This class is used to form augmentative singular nouns. The corresponding plural class is `Bantu22`.

#### Examples

* _omusaayi gwa-<b>gwo</b>_<br>
  NC3.blood NC3.PSED-**NC20.PSOR**<br>
  "**its** blood" (e.g. of a large animal; _gusolo_ 'large animal (NC20)')

### <a name="Bantu22">`Bantu22`</a>: noun class 22

The possessor marker of noun class 22 is _go_.
This class is used to form augmentative plural nouns. The corresponding singular class is `Bantu20`.

#### Examples

* _omusaayi gwa-<b>go</b>_<br>
  NC3.blood NC3.PSED-**NC22.PSOR**<br>
  "**their** blood" (e.g. of large animals; _gasolo_ 'large animals (NC22)')
