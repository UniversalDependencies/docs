This feature takes the following values: Prox, Remt.

### <a name='Prox'>`Prox`: Proximate
Used for near deixis, e.g. _ēn_ "this" or _ēdar_ "here".

### <a name='Remt'>`Remt`: Remote / distal
Used for far deixis, e.g. _ān_ "that" or _ānōh_ "there".
