Boolean feature of [NOUN](_oge/pos/NOUN), [PROPN](_oge/pos/PROPN), [PRON](_oge/pos/PRON), [NUM](_oge/pos/NUM), [ADV](_oge/pos/ADV), [PART](_oge/pos/PART), [VERB](_oge/pos/VERB). It indicates whether the common noun, proper noun, adverb is written in a shortened form using diacritics.

### <a name="Yes">`Yes`</a>: it is abbreviation


#### Examples

common noun: _ღ͠წლთა_ *ġ͠cltʻa* 'of achievements' etc.
proper noun: _ი͠ჳ_ *i͠w* 'Jesus' etc.
pronoun: _ყ͠თა_ *q͠tʻa* 'of everybody' etc.
numeral: Ⴇ&#x0360;
adverb: _ასამღ͠ლბ͠ლად_ *asamġ͠lb͠lad* 'for elevation' etc.
particle: _ხ͠_ *x͠* 'however' etc.
verb: _გ͠ნემზადე_ *g͠nemzade* 'be prapered' etc.
