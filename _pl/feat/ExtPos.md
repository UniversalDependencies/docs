This feature indicates, for the head of a [fixed expression](https://universaldependencies.org/u/dep/fixed.html),
the effective UPOS of the full expression when it differs from the UPOS of the word itself.
Occasionally, `ExtPos` is used even if `ExtPos` = `upos`.

### <a name="ADJ">`ADJ`</a>: adjective-like expression

#### Examples

* [pl] _<b>tak zwana</b> lista 500_ (_tak_ = `ADV`) "the <b>so-called</b> 500 list"

### <a name="ADP">`ADP`</a>: complex adposition

#### Examples

* [pl] _<b>w zależności od</b> rozwoju przestępczości_ (_w_ = `ADP`) "<b>depending on</b> the development of crime"

### <a name="ADV">`ADV`</a>: adverb-like expression

#### Examples

* [pl] _<b>na co dzień</b>_ (_na_ = `ADP`) "every day"

### <a name="AUX">`AUX`</a>: auxiliary-like expression

#### Examples

* [pl] _<b>niech</b> że_ (_niech_ = `AUX`) "3rd person imperative"

### <a name="CCONJ">`CCONJ`</a>: complex coordinating conjunction

#### Examples

* [pl] _<b>a więc</b>_ (_a_ = `CCONJ`) "so"


### <a name="DET">`DET`</a>: determiner-like expression

#### Examples

* [pl] _<b>taka sama</b>_ (_taka_ = `DET`) "the same"

### <a name="INTJ">`INTJ`</a>: interjection-like expression

#### Examples

* [pl] _<b>o dziwo</b>_ (_o_ = `INTJ`) "surprisingly"

### <a name="NOUN">`NOUN`</a>: noun-like expression

#### Examples

* [pl] _<b>hot dogiem</b>_ (_hot_ = `NOUN`) "hot dog.INST"


### <a name="PART">`PART`</a>: particle-like expression

#### Examples

* [pl] _<b>przede wszystkim</b>_ (_przede_ = `ADP`) "above all"

### <a name="PRON">`PRON`</a>: pronoun-like expression

#### Examples

* _<b>co nieco</b>_ (_co_ = 'PRON') "something"


### <a name="SCONJ">`SCONJ`</a>: complex subordinating conjunction

#### Examples

* [pl] _<b>jako że</b>_ (_jako_ = `SCONJ`) "as that"

### <a name="SYM">`SYM`</a>: complex symbol

#### Examples

* [pl] _<b>++</b>_ (_+_ = `SYM`) "++"


### <a name="VERB">`VERB`</a>: verb-like expression

#### Examples

* [pl] _nie <b>ma co</b> ukrywać_ (_ma_ = `VERB`) "there is nothing to hide"


### <a name="X">`X`</a>: foreign expression

#### Examples

* [pl] _<b>a priori</b>_ (_a_ = `X`) "a priori"
