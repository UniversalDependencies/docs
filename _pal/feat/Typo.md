This feature takes the following values: Yes.

### <a name='Yes'>`Yes`: explanation of the value
The typo feature is very important for manually copied historical texts. Whenever a writing is not as expected, it is marked as a typo. However, some variation is so frequent for a text that one could consider it th new (correct) way of writing.
