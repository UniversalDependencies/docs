In Tswana, this feature applies to words tagged as [pronouns](): Subject and object concords, demonstrative pronouns, emphatic pronouns, possessive pronouns and quantitative pronouns.


### <a name="Prs">`Prs`</a>: personal or possessive personal pronoun or determiner

See also the [Poss]() feature that distinguishes normal personal
pronouns from possessives. Note that `Prs` also includes reflexive
personal/possessive pronouns.

#### Examples

The following pronouns have this feature (if tagged as pronouns):

* _a, ba, bo, bone, bothle, di, e, ena, ene, eo, gago, go, jwa, ke, le, lo, me, mo, o, re, se, wena_


### <a name="Dem">`Dem`</a>: demonstrative determiner or adverb

#### Examples

The following pronouns have this feature:

* _eo_


### <a name="Tot">`Tot`</a>: total pronoun or determiner

#### Examples

The following quantitative pronouns have this feature:

* _bothle_


### <a name="Ind">`Ind`</a>: indefinite pronoun or determiner

#### Examples

The following pronouns have this feature if the XPOS is SC15:

* _go_
