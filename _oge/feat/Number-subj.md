`Number[subj]` is an inflectional feature of [verbs](_oge/pos/VERB).

### <a name="Sing">`Sing`</a>: singular number

#### Examples

* _ვწერ_ 'I write', _სწერ_ 'you write', _წერს_ 'he/she writes' etc.

### <a name="Plur">`Plur`</a>: plural number

#### Examples

* _ვწერთ_ 'we write', _სწერთ_ 'you write', _წერენ_ 'they write' etc.
