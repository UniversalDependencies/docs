The object marker on the verb reflects the number value of the object.

### <a name="Sing">`Sing`</a>: singular

Singular object prefixes include the first person singular _n-_, second person singular _ku-_, and a paradigm of singular noun classes for third person objects (see [NounClass[obj]]()). 

#### Examples

* _a<b>n</b>yamba_<br>
  NC1.SBJ-**1sg.OBJ**-help<br>
  "he helps me"

* _a<b>ku</b>yamba_<br>
  NC1.SBJ-**2sg.OBJ**-help<br>
  "he helps you (sg.)"

* _a<b>mu</b>yamba_<br>
  NC1.SBJ-**NC1.OBJ**-help<br>
  "he helps him"

### <a name="Plur">`Plur`</a>: plural

Plural object prefixes include the first person plural _tu-_, second person plural _ba-_, and a paradigm of plural noun classes for third person objects (see [NounClass[obj]]()). 

#### Examples

* _ba<b>tu</b>yamba_<br>
  NC2.SBJ-**1pl.OBJ**-help<br>
  "they help us"

* _ki<b>ba</b>yamba_<br>
  NC7.SBJ-**2pl.OBJ**-help<br>
  "it helps you (pl.)"

* _mu<b>ba</b>yamba_<br>
  2pl.SBJ-**NC2.OBJ**-help<br>
  "you help them"
