In Ruuli, objects are often marked on the verb as the object prefix, which follows the subject prefix (except for imperatives and infinitives, which do not have subject prefixes).
Third-person object markers agree with the object in noun class, according to the mapping in the table below.

| Noun Class (NC) |Object Prefix |
|------|--------|
| 1 | _mu-_ |
| 2 | _ba-_ |
| 3 | _gu-_ |
| 4 | _gi-_ |
| 5 | _li-_ |
| 6 | _ga-_ |
| 7 | _ki-_ |
| 8 | _bi-_ |
| 9 | _gi-_ |
| 10 | _zi-_ |
| 11 | _lu-_ |
| 12 | _ka-_ |
| 13 | _tu-_ |
| 14 | _bu-_ |
| 15 | _ku-_ |
| 20 | _gu-_ | 
| 22 | _ga-_ | 

The paradigm of object prefixes excludes locative classes 16, 17, 18, and 23 as they do not contain nouns and cannot be used as objects; 
Proto-Bantu noun classes 19 and 21 are not attested in Ruuli.

### <a name="Bantu1">`Bantu1`</a>: noun class 1

The object prefix of noun class 1 is _mu-_.
This class contains singular nouns, mostly for humans. The corresponding plural classes are `Bantu2` and `Bantu10`.

#### Examples

* _A-<b>mu</b>-boine._<br>
  NC1.SBJ-**NC1.OBJ**-see:PFV<br>
  "He has seen **him**."

### <a name="Bantu2">`Bantu2`</a>: noun class 2

The object prefix of noun class 2 is _ba-_.
This class contains plural nouns, mostly for humans. The corresponding singular class is `Bantu1`.

#### Examples

* _A-<b>ba</b>-boine._<br>
  NC1.SBJ-**NC2.OBJ**-see:PFV<br>
  "He has seen **them** (people)."

### <a name="Bantu3">`Bantu3`</a>: noun class 3

The object prefix of noun class 3 is _gu-_.
This class contains singular nouns. The corresponding plural class is `Bantu4`.

#### Examples

* _Omwigo, a-<b>gu</b>-taire awo._<br>
  NC3.stick NC1.SBJ-**NC3.OBJ**-put:PFV there<br>
  "The stick, she has put **it** there."

### <a name="Bantu4">`Bantu4`</a>: noun class 4

The object prefix of noun class 4 is _gi-_.
This class contains plural nouns. The corresponding singular class is `Bantu3`.

#### Examples

* _Emisale tu-<b>gi</b>-malere._<br>
  NC4.trees 1pl.SBJ-**NC4.OBJ**-finish:PFV<br>
  "The trees, we did away with **them**."

### <a name="Bantu5">`Bantu5`</a>: noun class 5

The object prefix of noun class 5 is _li-_.
This class contains singular nouns. The corresponding plural class is `Bantu6`.

#### Examples

* _Eisumu n-<b>li</b>-zwireku._<br>
  NC5.spear 1sg.SBJ-**NC5.OBJ**-leave:PFV<br>
  "The spear, I have abandoned **it**."

### <a name="Bantu6">`Bantu6`</a>: noun class 6

The object prefix of noun class 6 is _ga-_.
This class contains plural and uncountable nouns. The corresponding singular class is `Bantu5`.

#### Examples

* _Amagezi gani tu-<b>ga</b>-taka._<br>
  NC6.knowledge NC6.this 1pl.SBJ-**NC6.OBJ**-need<br>
  "This knowledge, we need **it**."

### <a name="Bantu7">`Bantu7`</a>: noun class 7

The object prefix of noun class 7 is _ki-_.
This class contains singular nouns. The corresponding plural class is `Bantu8`.

#### Examples

* _Ekisunsuzo n-<b>ki</b>-waire maama._<br>
  NC7.comb 1sg.SBJ-**NC7.OBJ**-give:PFV NC1.mother<br>
  "The comb, I have given **it** to my mother."

### <a name="Bantu8">`Bantu8`</a>: noun class 8

The object prefix of noun class 8 is _bi-_.
This class contains plural nouns. The corresponding singular class is `Bantu7`.

#### Examples

* _Ebisolo tu-<b>bi</b>-tega._<br>
  NC8.animals 1pl.SBJ-**NC8.OBJ**-hunt<br>
  "The animals, we hunt **them**."

### <a name="Bantu9">`Bantu9`</a>: noun class 9

The object prefix of noun class 9 is _gi-_.
This class contains singular nouns. The corresponding plural class is `Bantu10`.

#### Examples

* _Ensonga eyo n-ku-<b>gi</b>-tegera._<br>
  NC9.issue NC9.that 1sg.SBJ-PROG-**NC9.OBJ**-understand<br>
  "That issue, I understand **it**."

### <a name="Bantu10">`Bantu10`</a>: noun class 10

The object prefix of noun class 10 is _zi-_.
This class contains plural nouns. The corresponding singular classes are `Bantu1`, `Bantu9`, and `Bantu11`.

#### Examples

* _Enyanja tw<b>zi</b>zwireku._<br>
  NC10.lakes 1pl.SBJ-**NC10.OBJ**-leave:PFV<br>
  "The lakes, we have given up on **them**."

### <a name="Bantu11">`Bantu11`</a>: noun class 11

The object prefix of noun class 11 is _lu-_.
This class contains singular nouns. The corresponding plural class is `Bantu10`.

#### Examples

* _Olwowo o-<b>lu</b>-boine?_<br>
  NC11.wooden_plate 2sg.SBJ-**NC11.OBJ**-see:PFV<br>
  "The wooden plate, have you seen **it**?"

### <a name="Bantu12">`Bantu12`</a>: noun class 12

The object prefix of noun class 12 is _ka-_. 
This class contains singular and uncountable nouns. It is also used to form diminutive singular nouns. 
The corresponding plural class is `Bantu14`.

#### Examples

* _Ba-<b>ka</b>-sikaku akaita._<br>
  NC2.SBJ-**NC12.OBJ**-fry NC12.millet<br>
  "They fry **it**, the millet."

### <a name="Bantu14">`Bantu14`</a>: noun class 14

The object prefix of noun class 14 is _bu-_.
This class contains multiple abstract nouns. It is also used to form diminutive plural nouns. 
The corresponding singular class is `Bantu12`.

#### Examples

* _Obudooli obwo ba-<b>bu</b>-gaine._<br>
  NC14.small NC14.those NC2.SBJ-**NC14.OBJ**-refuse:PFV<br>
  "Those small ones, they have refused **them**."

### <a name="Bantu15">`Bantu15`</a>: noun class 15

The object prefix of noun class 15 is _ku-_.
This class contains deverbal nouns. There is no corresponding plural class.

#### Examples

* _okusomesya, ti-n-<b>kw</b>-endya_<br>
  NC15.teaching NEG-1sg.SBJ-**NC15.OBJ**-like<br>
  "Teaching, I don't like **it**." (_kw-_ is the surface form of the underlying _ku-_; the glide /w/ is conditioned by the following vowel)

### <a name="Bantu20">`Bantu20`</a>: noun class 20

The object prefix of noun class 20 is _gu-_.
This class is used to form augmentative singular nouns. The corresponding plural class is `Bantu22`.

#### Examples

* _ogubbambo, n-<b>gu</b>-bwoine_<br>
  NC20.big_basket 1sg.SBJ-**NC20.OBJ**-see:PFV<br>
  "The big basket, I have seen **it**."

### <a name="Bantu22">`Bantu22`</a>: noun class 22

The object prefix of noun class 22 is _ga-_.
This class is used to form augmentative plural nouns. The corresponding singular class is `Bantu20`.

#### Examples

* _Agajwenge, n-<b>ga</b>-bwoine_<br>
  NC22.big_boats 1sg.SBJ-**NC22.OBJ**-see:PFV<br>
  "The big boats, I have seen **them**."
