### <a name="Dem">`Dem`</a>: Demonstrative pronoun
Demonstrative pronouns can be proximal (like _ēn_) and remote (like _ān_), but there function in discourse reference has not been fully understood yet.
#### Examples:
- "this" _ēn, ēd, im_
- "that" _ān, ōy_
- "those" _awēšān_

### <a name="Emp">`Emp`</a>: Emphatic pronoun
The reflexive pronoun _xwad_ can be used as an intensifier, in case of which it receives the feature emphatic. Negation can be emphasized by using _tisiz_ lit. "even something"
#### Examples
- _dušox <b>xwad</b> tisē wattar kū bīm_ "Hell **itself** (is) something worse than fear."
- _u=šān <b>xwad</b> pad xwad ān ī abārōn arešk abar burd_ "And they **themselves** brought sinful envy upon themselves."
- _ud <b>tisiz</b> bazag az mardōmān **nē** raft_ "And no wrongdoing **at all** started from humans."

### <a name="Exc">`Exc`</a>: Exclamative pronoun
The exclamative determiner is _čē_. It has not been attested in the corpus yet.
#### Examples
- _<b>čē</b> xūb_ / _what good_ i.e. "That's good!"

### <a name="Ind">`Ind`</a>: Indefinite pronoun
Indefinite pronouns.
#### Examples:
- _čand_ "some"

### <a name="Int">`Int`</a>: Interrogative pronoun
Interrogative pronouns. They can be used as relative pronouns and interrogative determiners.
#### Examples:
- _kē_ "who"
- _čē_ "what"
- _kū_ "where"
- _kay_ "when"
- _čiyōn_ "how"

### <a name="Neg">`Neg`</a>: Negative pronoun
The only pronoun marked inherently as negative is _ēč_ "any", which usually occurs with a negated predicate.
#### Examples
- _ud pad <b>ēč</b> rāh ruwān ī xwēš **nē** āzāred_ "And (it) does not harm his soul in **any** way."

### <a name="Prs">`Prs`</a>: Personal pronoun
Personal pronouns have orthotone and enclitic forms.
#### Examples
||orthotone|enclitic|
|---|---|---|
|1sg.|_man_ (direct _an_)|_=m_|
|2sg.|_tō_|_=t_|
|3sg.|_ōy_ (variant _away_?)|_=š_|
|1pl.|_amāh_|_=mān_ (archaic _=n_)|
|2pl.|_ašmāh_|_=tān_|
|3pl.|_awēšān_|_=šān_| (archaic _=š_)|

### <a name="Rcp">`Rcp`</a>: Reciprocal pronoun
The reciprocal pronoun is _ham_. Elements of analytic expressions such as _ēk ō did_ "one to the other" i.e. "to each other" are annotated individually.
#### Examples
- _ham_ 'each other'

### <a name="Rel">`Rel`</a>: Relative pronoun
The word _ī_, which is also used as a [linker](det) for attributes to their headword, and all interrogative pronouns can be used as relative pronouns.
#### Examples
- _būd **kū** gumēzagīh dēn andar gēhān bē raft_ "**Where** there was mixing, the Dēn went out into the world."

### <a name="Tot">`Tot`</a>: Total pronoun
Total pronouns are _harw_ "every", _hamāg_ and _(har)wisp_ "all".
