The `PronType` feature typically applies to [pronouns](_oge/pos/PRON).

### <a name="Prs">`Prs`</a>: personal pronoun

See also the [Poss](_oge/feat/Poss) feature that distinguishes normal personal pronouns from possessives. possessive pronouns ('Poss=Yes')

#### Examples

* _მე_ 'I', _შენ_ 'you', _ჩუენ_ 'we' etc.

### <a name="Dem">`Dem`</a>: demonstrative pronoun

#### Examples

* _ესე_ 'this', _ეგე_ 'that', _ესრჱთი_ 'this kind of' etc.

### <a name="Ind">`Ind`</a>: indefinite pronoun

#### Examples

* _ვინმე_ 'someone', _რაჲმე_ 'something', _ზოგი_ 'some' etc.

### <a name="Int">`Int`</a>: interrogative pronoun

#### Examples

* _ვინ_ 'who', _რა, რაჲ_ 'what', _რაოდენი_ 'how many' etc.

### <a name="Tot">`Tot`</a>: determinal pronoun

#### Examples

* _ყოველი_ 'each', _სხუაჲ_ 'other', _თავადი_ 'himself/herself/themselves' etc.

### <a name="Neg">`Neg`</a>: negative pronoun

#### Examples

* _არავინ_ 'nobody', _ვერვინ_ 'no-one', _არარაჲ_ 'absolutely no-one' etc.

### <a name="Rel">`Rel`</a>: relative pronoun

#### Examples

* _ვინ-ცა_ 'whoever', _რაჲ-ცა_ 'whatever', _ვინ-ესე_ 'this person who', _რაჲ-ესე_ 'that thing which'  etc.

### <a name="Rcp">`Rcp`</a>: reciprocal pronoun

#### Examples

* _ერთიერთი_ 'each other', _ურთიერთას_ 'each other' etc.
