Converb types distinguish temporal converbs and converbs expressing logical relations.  


### <a name="Imm">`Imm`</a>: immediate  

The immediate anterior converb encodes an event which immediately precedes the event in the matrix clause.

#### Examples

* _w-ak'-a-<b>rijal</b>_ : M-come:PFV-IRR-<b>IMM</b> "just after he came"


### <a name="Purp">`Purp`</a>: purposive  

#### Examples

* _hil-d-ix-<b>alis</b>_ : PV-F1-lie.down:PFV-<b>PURP</b>  "in order for her to go to sleep"


### <a name="Cond">`Cond`</a>: conditional  

#### Examples

* _g-a-<b>k'a</b>_ : give:PFV-IRR-<b>COND</b>  "if (s)he gave"
* _nu, di-la urši-li-ni xunul k-a-k'a, iχ-di-li-šu-r d-uʔ-es-i_ : I I.OBL-GEN boy-OBL-ERG wife bring:PFV-IRR-COND that-PL-OBL-AD-HPL(ESS) F1-be-INF-ATR "<b>If</b> my son <b>marries<b>, I will live at their place"


### <a name="Conc">`Conc`</a>: concessive  

#### Examples

* _ħa-g-a-<b>k'ara</b>_ : NEG-give:PFV-IRR-<b>CONC</b> "though (s)he did not give"


### <a name="Post">`Post`</a>: posterior  

#### Examples

* _b-ak'-<b>ače</b>_ : HPL-come:PFV-<b>PSTR</b> "before they came"


### <a name="Smlt">`Smlt`</a>: simultaneous  

#### Examples

* _b-elč'-un-<b>ijadal</b>_ : N-read:PFV-AOR-<b>SMLT</b> "as soon as (s)he reads"


### <a name="Cntf">`Cntf`</a>: counterfactual  

#### Examples

* _w-aq"-un-<b>q'alle</b>_ : M-do:PFV-AOR-<b>CTRF</b> "if he had done"


### <a name="Incp">`Incp`</a>: inceptive  

#### Examples

* _w-ak'-ib-i-<b>čela</b>_ : M-come:PFV-AOR-PTCP-<b>INCP</b> "since the moment he came"


### <a name="Loc">`Loc`</a>: locative  

Locative is weakly attested in Mehweb.  

#### Examples

* _b-ix-ib-i-ħe-<b>w</b>_ : N-put:PFV-AOR-PTCP-IN-<b>M(ESS)</b>  "where I put it"


### <a name="Ant">`Ant`</a>: anteriority  

#### Examples

* _b-ak'-ib-i-<b>ʁale</b>_ : HPL-come:PFV-AOR-PTCP-<b>ANTE</b> "when (after) they came"


### <a name="Grad">`Grad`</a>: gradual  

#### Examples

* _b-elč-un-i-cad(i)_ : N-read:PFV-AOR-PTCP-<b>GRAD</b> "the more (s)he has read"


### <a name="Caus">`Caus`</a>: causal  

#### Examples

* _d-ak'-i-le-<b>na</b> : F1-come:PFV-AOR-CVB-<b>CAUSAL</b> "because she came"


### <a name="Conc2">`Conc2`</a>: concessive  

Second concessive converb is used when the event described by the converbal clause was unlikely to happen and probably undesirable; but since it nevertheless did happen, the action in the main clause takes place. So its meaning is close to concession and causality.

#### Examples

* _ħu w-ak'-i-<b>leʡur</b>, nuša-ni ħa-d ʡoˤχlad-deš d-aq'-iša_ : you.sg(NOM) M-come:PFV-AOR-PTCP?-<b>CONC2</b> we-ERG you-DAT hospitable-NMLZ NPL-do:PFV-FUT.EGO "<b>As you have come here</b>, we will show you hospitality."
